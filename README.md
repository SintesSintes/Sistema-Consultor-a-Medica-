# Sistema-Consultor-a-Medica-


Aplicación de escritorio desarrollada en Java utilizando Programación Orientada a Objetos y Swing para la interfaz gráfica. El sistema permite gestionar pacientes, médicos y turnos de manera simple e intuitiva.

Funcionalidades

Registro y gestión de pacientes

Alta y administración de médicos

Asignación y control de turnos

Interfaz gráfica amigable

Validaciones básicas de datos

Tecnologías

Java

Swing

POO (encapsulamiento, herencia, polimorfismo)

Ejecución

Clonar o descargar el repositorio

Abrir el proyecto en tu IDE Java favorito

Ejecutar la clase Main

Objetivo

Proyecto educativo enfocado en aplicar conceptos de POO y desarrollo de interfaces gráficas en Java.
